# SiteAsset Pro - Bulk Web Asset & SVG Extractor

> Extract, preview, and download all SVGs, WebP, PNGs, and CSS background assets from any active webpage in 1 click. Zero server dependency, 100% on-device.

## Features
- **Deep SVG Extractor:** Scans all inline `<svg>` and `<image>` vectors, extracting clean markup ready for Figma and React.
- **Client-Side ZIP Generator:** Package all assets or selected items into a ZIP bundle right inside the browser.
- **CSS Background Inspector:** Detects high-resolution hero banners and CSS background patterns.
- **Privacy First:** 100% on-device processing. No external API calls or analytics.

## Installation
1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select this directory.
